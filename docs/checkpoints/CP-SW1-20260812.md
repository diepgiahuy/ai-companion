# CP-SW1 — Realtime turn runtime + streaming response foundation

Date: 2026-08-12
Status: ✅ gate passed in the available offline functional environment

## Goal

Make the server realtime path production-shaped before changing hardware: model streaming can overlap TTS, and user interruption invalidates every stale queued turn output.

New regression cases:

- streaming model is deliberately blocked after first clause; server starts TTS before the model is allowed to finish;
- stale turn-scoped outbound data becomes invalid immediately after interruption;
- punctuation segmentation handles Vietnamese/English clauses and flushes tails.

## Difficulty

Cancelling a provider context is not enough for barge-in: audio frames may already be queued in the server or buffered on the device.

## Solution

Every turn has a monotonically increasing generation. Turn-scoped outbound items carry that generation. Interruption invalidates the generation; the single writer discards stale queued items. A non-scoped terminal `turn/interrupted` control message survives invalidation so the device can clear already-buffered local playback.

## Trade-offs

- A packet already written to the network cannot be recalled; device-side buffer clear is still required.
- Legacy raw WebSocket Opus frames are preserved; no incompatible wire header was introduced in this checkpoint.
- Sentence segmentation is deterministic and low-risk, but prosody/threshold tuning remains a later benchmark concern.
- ADK is deliberately not half-integrated without the exact Go 1.26.5 dependency environment. The existing agent remains the rollback path.
