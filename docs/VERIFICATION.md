# Historical verification record

## Current verification model

Use these sources instead:

- PR description — execution explanation, direct local oracle, evidence boundary and remaining work for one change.
- GitHub Checks/artifacts — hosted automated proof for reviewed code.
- [`../evidence/status.json`](../evidence/status.json) — only promoted evidence claims.
- [`TEST_EVIDENCE_LADDER.md`](TEST_EVIDENCE_LADDER.md) — what each test tier is allowed to prove.
- [`../ai_development_workflow.md`](../ai_development_workflow.md) — risk-matched testing, no-duplicate rule and exact-head merge proof.
- `main` — merged implementation truth.

Do not append a new hand-maintained current-status or command transcript here. Normal implementation proof belongs in the PR and Checks; immutable release/physical/provider artifacts belong in the evidence mechanism appropriate to that claim.

## Historical content

The detailed earlier verification log remains available through Git history for forensic or migration review. It must not be used to infer current database, provider, protocol, firmware, CI, branch or hardware evidence state.
